# 快速上手（3 步）

只需三步，你就能把 CaspianFlow 用起来。本指南对应首次启动时的引导教程。

## 第 1 步：认识你的本地数据

CaspianFlow 是本地优先应用。打开后，留意侧边栏底部的信任标识：

> **数据在本地 · ~/.caspian/**

这意味着：

- 对话、技能、知识库、记忆都只存在你的电脑上。
- 没有账号、没有强制联网，断网也能用。
- 想备份或迁移？在「设置 → 数据导入/导出」生成一个 `.caspian` 包即可。

## 第 2 步：发起你的第一次对话

1. 在左侧会话列表点 **＋ 新对话**（或命令面板 `Cmd/Ctrl + K` → 新建会话）。
2. 在底部输入框描述你的任务，例如：
   - “读取 `~/notes/todo.md` 并帮我按优先级整理”
   - “抓取下 https://example.com 的标题并总结”
   - “用 Python 算一下 1 到 100 的和”
3. 智能体会自动选择合适的**内置技能**完成任务，并在回答中说明用了哪些技能。

> 不确定能做什么？看 [内置技能](skills.md) 了解全部 17 个开箱即用能力。

## 第 3 步：把重复工作变成工作流

当你发现某类任务反复出现（如“每天汇总新闻 → 写入笔记”）：

1. 打开「工作流」页，新建一个工作流。
2. 在可视化编辑器里把技能节点按顺序串联。
3. 保存后，可一键运行，或用命令面板触发。

详见 [工作流](workflows.md)。

完成这三步，你已经掌握了 CaspianFlow 的核心用法。接下来：
