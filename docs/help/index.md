# CaspianFlow 帮助中心

CaspianFlow 是一款**本地优先（local-first）**的 AI 智能体运行时：你的对话、技能、知识库与记忆全部保存在本机 `~/.caspian/` 目录，不上传云端、可离线运行。

## 这份文档能帮你什么

- **第一次用？** 先看 [快速上手（3 步）](getting-started.md)。
- **想用现成能力？** 看 [内置技能](skills.md)——17 个开箱即用的系统技能。
- **想串起多步任务？** 看 [工作流](workflows.md)。
- **想提速？** 看 [键盘快捷键](keyboard-shortcuts.md)。
- **还有疑问？** 看 [常见问题 FAQ](faq.md)。

## 三大核心概念

1. **对话（Chat）**——你与智能体的主界面，智能体按需调用技能与知识库。
2. **技能（Skills）**——可复用的能力单元（读文件、抓网页、跑 Python 等），有显式权限边界。
3. **知识库（Knowledge）**——导入文档后自动生成向量，供智能体检索。

## 数据安全与自愈

- 所有数据在本地。导出/导入使用 `.caspian` 包（见设置页）。
- 启动时自动做数据库完整性检查（`PRAGMA integrity_check`），损坏库会从最近备份自动恢复；配置损坏会被记录但不阻塞启动。
- 离线时，依赖网络的技能会被自动降级，本地技能照常工作。

> 提示：随时按 **F1** 呼出本帮助面板，按 **Cmd/Ctrl + K** 打开命令面板。
