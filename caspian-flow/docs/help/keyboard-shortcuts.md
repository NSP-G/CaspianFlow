# 键盘快捷键

高效使用 CaspianFlow 的快捷键一览。

## 全局快捷键

| 快捷键 | 作用 |
|--------|------|
| `F1` | 呼出 / 关闭**帮助面板**（本文档） |
| `Cmd/Ctrl + K` | 打开**命令面板**（新建会话、切换页面、运行工作流等） |

## 通用操作

| 操作 | 方式 |
|------|------|
| 新建对话 | 侧边栏 **＋**，或命令面板 → 新建会话 |
| 切换页面 | 侧边栏图标，或命令面板 |
| 切换主题 | 设置页 → 主题（深色 / 浅色），或应用自定义主题包 |
| 折叠侧边栏 | 设置或侧边栏折叠按钮 |

## 提示

- 命令面板是最高效的入口：几乎任何操作都能通过 `Cmd/Ctrl + K` 触发。
- 帮助面板（`F1`）会在你工作的任意页面浮层显示，不会打断当前上下文。
- 若快捷键无响应，确认焦点不在输入框内（输入态下 `F1` 可能被浏览器占用）。
