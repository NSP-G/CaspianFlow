# 工作流

工作流（Workflow）让你把多个技能按顺序串联，沉淀为可一键复用的多步任务。

## 什么时候用工作流

- 每天/每周重复的流程（如“汇总新闻 → 写入笔记”）。
- 需要明确步骤与顺序的复杂任务。
- 想让他人也能一键运行同一套流程。

## 创建与编辑

1. 打开「工作流」页，点 **新建工作流**。
2. 在可视化编辑器（基于节点画布）里：
   - 从左侧拖入技能节点（如 `file-reader`、`code-interpreter`）。
   - 用连线把节点按执行顺序串起来。
3. 为每个节点配置输入（可引用上一步的输出）。
4. 保存工作流。

## 运行

- 在「工作流」页点某个工作流 **运行**。
- 或在命令面板（`Cmd/Ctrl + K`）中选择对应工作流。
- 运行过程与每一步输出会记录为一次“运行”，可在历史中查看。

## 与技能的配合

- 工作流节点本质上是技能调用，受同样的**权限边界**约束。
- 需要外部代码（如从 GitHub 引入的技能）时，工作流会经由沙箱（P32）隔离执行。

## 故障排查

- 某步失败：查看该运行的历史，定位出错的节点与日志。
- 权限不足：检查该技能在「技能」页是否启用、其文件系统/网络/shell 权限是否满足。
- 想了解可用技能清单，见 [内置技能](skills.md)。
