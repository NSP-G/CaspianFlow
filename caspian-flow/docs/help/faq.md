# 常见问题（FAQ）

## 1. CaspianFlow 把我的数据存在哪里？

全部存在本机 `~/.caspian/` 目录：会话在 `sessions/`，知识库在 `knowledge/`，技能在 `skills/`，记忆在 `MEMORY.md`，配置在 `config/settings.yaml`。没有云端账号，数据默认不离机。

## 2. 断网时还能用吗？

能。本地技能（读文件、跑 Python、解析 JSON 等）完全离线可用。依赖网络的技能（`web-fetcher`、`http_request`）会在离线时被**自动降级**禁用，联网后恢复。

## 3. 怎么备份或迁移我的数据？

打开「设置 → 数据导入/导出」，导出一个 `.caspian` 包（包含技能、会话、记忆、配置、知识库索引）。把它拷到另一台机器，再用导入功能恢复即可。

## 4. 内置技能不够用，能装更多吗？

可以。除 17 个内置技能外，支持从本地目录、Git 仓库、HTTP 链接、以及 MCP 服务器加载外部技能（见「技能」页与设置页）。外部代码会在沙箱（P32）中隔离运行。

## 5. 智能体会不会乱读我的文件？

不会。每个技能都有**显式权限声明**，限定可读/可写的路径前缀、是否允许网络与 shell。智能体只能调用被授权范围内的能力。

## 6. 数据库损坏了怎么办？

无需手动处理。启动时自动执行 `PRAGMA integrity_check`；若发现损坏，会从最近备份自动恢复，并把损坏文件改名为 `.corrupt-<时间戳>` 供你取证。备份通过 `VACUUM INTO` 生成，默认保留最近 7 份。

## 7. 为什么有些技能显示“已降级/禁用”？

通常是离线导致网络类技能被自动降级，或你在「技能」页手动禁用了它。重新联网或重新启用即可。

## 8. 怎么把重复任务自动化？

把它做成「工作流」：在可视化编辑器里把技能节点串联保存，之后一键运行或用命令面板触发。详见 [工作流](workflows.md)。

## 9. 支持自定义主题吗？

支持。在「设置 → 主题」可切换内置深色/浅色，也可安装自定义主题包（P31）。

## 10. 启动很慢 / 内存占用高怎么办？

核心（Rust）启动通常在毫秒级，体感慢主要来自前端与 webview 加载。可尝试：关闭不必要的页面、延迟加载重依赖。真实 GUI 启动/内存数字请在本地 `tauri dev` 下用 Performance 面板与 `RUST_LOG=info` 的 `startup:` 日志读取。

## 11. 导入知识库后搜索不到内容？

知识库导入依赖嵌入模型；若本地没有模型，文档会被放入“失败”桶而非静默丢弃。请先确保已预载嵌入模型，再重新导入该文档。

## 12. 命令面板（Cmd/Ctrl + K）能做什么？

几乎任何操作：新建会话、切换页面、运行工作流、打开设置等。它是最高效的统一入口。

## 13. 帮助面板（F1）会打断我当前的工作吗？

不会。它以浮层形式覆盖在当前页面之上，关闭后回到原上下文。

## 14. 我不想每次都看引导教程，怎么跳过？

首次启动的 3 步引导只出现一次；关闭后即记住你的选择，后续启动直接进入主界面。仍可在帮助中心随时回顾 [快速上手](getting-started.md)。
